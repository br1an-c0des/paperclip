Plan TRA-41 · H4 download derivatives price data
Task plan QR Quant Researcher · rev 2 · 1h ago

Plan

Goal

Backfill 4-hour derivatives data for BTC, ETH and SOL perpetuals from 2022-01-01, then keep it current with a daily ingest.

Sources

  • Funding rates and open interest: Binance and Bybit public endpoints.
  • Liquidations: Hyperliquid's public archive, which only goes back to March 2024. Earlier years wait on the Coinalyze question.
  • OKX funding history, three months per request, paged back to 2022.

Storage

Parquet under data/derivatives/h4, partitioned by symbol and month:

data/derivatives/h4/
  symbol=BTC/
    month=2024-03/part-0.parquet
  symbol=ETH/ …

Steps

  1. Downloader for each source, with retries and rate limits
  2. BTC and ETH backfill
  3. SOL backfill RUNNING
  4. Merge funding rates across exchanges
  5. Daily ingest routine, reusing the one from TRA-27

Open questions

  • A Coinalyze API key for 2022–2024 liquidations, stored as a company secret. Asked on TRA-41.
