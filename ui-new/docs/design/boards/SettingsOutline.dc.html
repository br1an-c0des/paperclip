Settings outline

Every section of organization, agent and app settings: what it holds and where it comes from in the current UI. Settings live with the thing they configure; only account and instance settings stand alone. Sections marked Mocked have a board; the others open as an outline when picked in the section nav.

Organization settings

Cuebik Creative · 8 sections

General

Mocked · board 21

Who the organization is, and its rules for hiring and for answering agents.

  • Organization. Name, description and logo.
  • Default owner. The person who gets tasks and requests that have no owner.
  • Hiring. Require approval before a new agent starts work.
  • Agent requests. For each kind of request, who may answer it: people only, anyone except the asking agent, or anyone.
  • Feedback sharing. Whether rated agent outputs are shared with Paperclip.
  • Danger zone. Pause every agent; archive the organization.
From the current UI: Company settings → General

Members

Mocked · board 22

The people in the organization, their roles, and how new people get in.

  • Members. People and roles (Owner, Admin, Operator, Viewer); change a role, suspend, remove.
  • Invites. Create an invite link with a role; copy or revoke pending invites.
  • Join requests. Approve or reject requests to join. They also arrive in the Inbox.
From the current UI: Company settings → Members; Inbox → Join requests

Connections

Mocked · board 23

The models Paperclip itself uses, and where run telemetry goes.

  • Decision model. The shared connection for Paperclip decision features, with a test and usage link.
  • Fast responses. A quick acknowledgement while the agent prepares its full reply.
  • Prompt injection check. A model check on tool results, a pattern fallback, and a test.
  • Run telemetry. An OpenTelemetry endpoint for managed Claude Code and Codex runs, with a test.
From the current UI: Company settings → Connections; General → Agent observability

Secrets

Mocked · board 24

Keys and tokens agents use, where they are stored, and requests for new ones.

  • Organization secrets. Create, edit, rotate, delete; see which agents use each one.
  • Requests from agents. Secrets an agent asked for: add the value or decline.
  • Providers. Paperclip vault and external stores such as AWS Secrets Manager: setup, discovery, health.
  • Per-person secrets. Secrets each person sets for themselves, and your own values.
From the current UI: Company settings → Secrets

Budgets

Mocked · board 25

Monthly limits for the organization, its agents and its projects, in one place.

  • Organization budget. Monthly limit, warning threshold, and what happens when it is reached.
  • Agents and projects. Every budget in one table, with spend so far and the action at the limit.
  • Incidents. Budgets that were reached, and what was done about it.
From the current UI: Activity → Budgets (spend charts stay in Activity → Costs)

Environments

Outline

Where this organization’s agents run.

  • Environments. Local, SSH, sandbox and plugin environments: create, edit, delete.
  • Health. Probe an environment and see what it can do (git, browser, Docker).
  • Custom images. Build and test a sandbox image step by step.
  • Terminal. Open a terminal in an environment.
  • Default. The environment agents use unless their settings say otherwise.
From the current UI: Instance settings → Environments (the API is per organization, so it moves here)

Import and export

Outline

Move an organization between Paperclip instances.

  • Export. Choose what to include (agents, projects, skills, routines), preview it, read the fidelity report.
  • Import. Upload a package or start a transfer, preview it, create or merge, follow progress.
From the current UI: Company export, Company import

  • Plugin page. Rendered by the plugin inside this layout.

Agent settings

Quant Researcher · 10 sections

Agent

Profile

Outline

Who this agent is, where it sits in the org, and its lifecycle.

  • Identity. Name, title, avatar and color, and the description other agents read.
  • Reports to. Its manager in the org chart.
  • For you. Make it your primary agent; show it in your sidebar.
  • Lifecycle. Pause or resume, clear an error, reset its sessions, retire it.
From the current UI: Overview (identity), Harness / Runtime (name, title, reports to), header actions

Instructions

Mocked · board 27

The files that tell the agent how to work.

  • Files. Edit, add, delete and download instruction files; one is the entry file.
  • Proposed changes. Edits a run suggested: view the diff, accept or reject.
  • History. Earlier versions; restore one.
From the current UI: Instructions

Skills

Outline

What the agent knows how to do.

  • Assigned skills. Skills from the library, with the version each one uses.
  • Sync. Update to the library’s latest versions.
  • Add. Pick more skills from the library.
From the current UI: Skills

How it runs

Model and runtime

Mocked · board 26

How the agent runs: harness, model, environment, when it wakes, and its limits.

  • Harness and model. Harness, sign-in, model, thinking effort, Paperclip Runner upgrade, environment test.
  • Where it runs. Environment, browser access.
  • When it wakes. On demand, on a heartbeat, cooldown, concurrent runs.
  • Run limits. Timeout, grace period, continuing after a max-turn stop.
  • Debugging. Raw provider traces.
  • Advanced. Command, arguments and prompt templates.
From the current UI: Harness / Runtime

Tools and channels

Outline

The apps and chat channels the agent can use.

  • Apps and MCP servers. Connections the agent may use; add or remove them.
  • Tool profile. Which tools a run gets, and the policies that apply.
  • Recent decisions. Tool calls that were allowed, asked about, or blocked.
  • Channels. Slack, GitHub and other chat channels connected to the agent.
From the current UI: Tools, Channels

Secrets and variables

Outline

Values the agent’s runs receive.

  • Variables. Plain environment variables.
  • Secrets. Organization or personal secrets passed to runs by reference.
From the current UI: Secrets

Budget

Outline

How much the agent may spend each month.

  • Monthly limit. Limit, spend so far, and what happens at the limit.
  • Costs. A link to Activity → Costs filtered to this agent.
From the current UI: Activity → Budgets and Costs, filtered to the agent

Governance

Permissions and trust

Outline

What the agent may do without asking.

  • Trust preset. Standard, or low-trust review with a boundary (projects, tasks, agents, tools, secrets).
  • Permissions. Hire agents, create skills, assign tasks.
  • Effective policy. The full policy that results.
From the current UI: Permissions / Trust

API keys

Outline

Keys that let outside tools act as this agent.

  • Keys. Create (shown once), list, revoke.
From the current UI: API Keys

History

Outline

Every change to the agent’s configuration, and everything it did.

  • Revisions. Who changed what and when; compare; roll back.
  • Action log. The agent’s actions, exportable as CSV.
From the current UI: Revisions; Activity → Agent actions audit
