Agent avatars

Every image here was rendered by Paperclip's own ClipLab cap-v1 renderer in packages/shared/src/cliplab: the same SVG snapshot the server turns into /api/agent-avatars/cap-v1/<palette>/<pose>.png. Each agent stores one of 17 palettes; the pose follows its status. In the app, AgentCharacter lets one avatar at a time play live in three.js and every other placement shows these stills. The animated row replays frames sampled from the real animation timelines, so no 3D library loads in the boards.
