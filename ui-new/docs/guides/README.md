# Guides

Notes toward a user-facing guide to Paperclip: what it is, what it can do, and how and when to use
each feature, with worked examples and flows. Upstream's documentation mostly explains how features
work and how to configure them; it rarely says why you'd pick one, or walks through using it end to
end. These notes fill that gap as features come up in the redesign.

They're raw material for two things:

- a written "how to use Paperclip" guide;
- an interactive guide built into `ui-new` ([build plan 3.15](../build-plan.md#315-an-in-app-guide-to-paperclip)),
  not designed or scheduled yet.

Each guide says what the feature is for, when it helps and when it doesn't, an example flow, and
where `ui-new` stands on it. Keep sources (upstream docs, pull requests and issues) at the end, so
claims can be checked as upstream changes.
