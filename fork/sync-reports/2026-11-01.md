## Upstream changes

Most of this batch prepares the server for ephemeral, replaceable web servers. Skills, agent
files, run logs, workspaces and live sessions move to Postgres and S3, and one web server can hand
over to another. The rest is:

- Runner work: native Kimi Code and gated Google Antigravity.
- More background work driven by deadlines and committed changes.
- Chat and Coordinator speed-ups.
- About 45 eval, E2E and CI commits.

### Larger new features

- **Managed skills, with version checks** (`0e15c9207`, #18334).
  - A new source type `managed`, with a null locator, the `paperclip` badge and the label
    "Paperclip".
  - Writes accept an optional `expectedVersionId` and answer 409 when stale.
  - The old Studio gained a conflict banner.
  - Restore is now `POST .../versions {sourceVersionId, expectedVersionId}`.
  - Migration 0417 adds `company_skill_mutation_receipts`.
- **Volume-free web server handoff** (`006d5691a` #18518, plus `d941ed387`, `7751fc310`,
  `c0550e701`, `1a6017d64`, `16787e416`, `73cd8eb9a`).
  - Agent files go to PG and S3 (migration 0422, `agent_file_roots`).
  - Adds `GET/HEAD /api/ready`.
  - Requests drain and controllers recover across a replacement.
  - Adds the `live.resync` reason `controller_change`.
- **Remote workspaces off the web server's disk** (`5e4cc0107` #18403, migration 0421,
  `execution_workspace_snapshots`).
  - A new instance flag, `remoteWorkspaceStorageEnabled`.
  - Workspace file APIs gain an optional `source` (live or saved).
  - Related: tasks in metadata-only projects get private remote workspaces (`1e8e32290`).
- **Run logs and provider traces in S3** (`dbff3747b`, #18327).
- **Proactive task messages to agent chats** (`8ff812cdd` #18374, migration 0419).
  - Adds `POST /agents/me/chat/messages`, and comment metadata `chatMessage`.
  - Chats carry `isUnreadForMe` and `lastExternalCommentAt`.
  - `POST /issues/:id/read` takes `throughCommentId`, with a strict schema.
- **Chat history paging** (`6dcf4160d`, #18358): `recent-comments` returns a chat's 20 newest
  comments with `oldestCommentId`.
- **Native Kimi Code** (`b866fa4bd`, `59da15066`, `8c9dd1e44`) and **gated Google
  Antigravity** (`09c05c550`, `54cc522e8`, `61bd4ac69`).
  - Both need operator candidate admission.
  - Antigravity shows up through `candidateHarnesses` and signs in with a Google subscription.
- **Task plugin panels** (`35ab90ad0` #18131, `b05602640` #18363).
  - Activation mappings and `?view=plugin-panels`.
  - Manual opening while idle, and availability called with `runId` and `issueId`.
  - Plugins can also use the GitHub credential broker (`e2cfdc7e0`).
- **Attention summary and task index** (`aa58fa107`, #18323): `GET .../attention/summary` and
  `.../attention/tasks`.
- **Old UI features:**
  - Image galleries in task documents (`cd5f93055`).
  - A Routine tasks filter (`b31ec0a2d`).
  - Inline agent-created subtasks (`909e29dd0`).
  - First onboarding limited to Claude and Codex (`59e191c36`).
  - GitHub review finding categories (`34f8d2508`).
  - Batched run reads with `?runIds=`.
