## Upstream changes

**439 upstream commits** (`d3713d827..f6cb3e43f`, 2026-11-05 – 2026-11-07)

About two thirds of the batch is restart safety: native Runner and recovery fixes, a new
durable-ownership and reconciliation layer, crash points, and a restart-chaos test harness. For the
board, four changes matter: Coordinator and Agent Chat become standard; Coordinator's navigation is
regrouped (Inbox, with Mine inside Tasks and All tasks by default); task Properties gets a
context-window meter with "Compact now"; and routines get a responsible-user picker. There are 14
migrations.

### Larger new features

- **Coordinator and Agent Chat become standard** (`f2593b790`, #19360). Coordinator is now the default workspace for everyone. The old Coordinator experiment value is ignored. Classic is a new per-person opt-in in Experimental settings (migration 0433 sets `coordinator_workspace_enabled` to default true and adds `classic_workspace_enabled`). `enableAgentChat` now defaults to true and is a "Deprecated compatibility key": the server's `getExperimental()` always returns true, and stored or managed off values are ignored. Task-link prefetch now warms the compact task and recent-comment queries, and Chat reuses the conversation-list data. Not behind a flag any more.
- **Inbox and Tasks regrouped in Coordinator** (`4550253dc`, #19363; `f8cb4957d`, #19393). Coordinator's "Needs you" entry is renamed Inbox and gets the inbox icon. The old Inbox item under More is removed, and old Inbox URLs redirect into Tasks. Tasks now hosts Mine, Unread, Recent, Blocked and Everything through the existing personal-inbox code (read and unread state, archive and undo, swipe, grouping, saved columns). A follow-up makes All tasks the first-visit default and leaves the "Last updated" header unhighlighted until someone picks a sort. Organization table columns are saved per person and company. There are no API changes.
- **Context window and Compact now in task Properties** (`bf10bc695`, #19273; `6ca7b151f`, #19378; `384fa2b7b`, #19801):
  - Properties gets a Context row ("10% of 258k") with a hover breakdown of tokens, cost and compactions.
  - The transcript shows a compaction divider.
  - New requests: `GET /issues/:id/context-usage` (type `IssueContextUsage`, with a `compaction` state) and `POST /issues/:id/context/compact` (board only). The compact request queues a short run that does no task work.
  - It works while an Agent Chat is waiting. Migration 0432 adds the supporting indexes.
- **Routine responsible user** (`21d2a577b`, #19128). A searchable person picker sits beside Default agent. `PATCH /routines/:id` accepts `responsibleUserId`, and `RoutineDetail.canChangeResponsibleUser` says who may change it (`tasks:assign`, instance admins, local operators). Each change is saved as a revision and recorded in the activity log.
- **Agent-created task trees limited to parent → child** (`958f9aa9f`, #19312):
  - An agent asking for a deeper task gets it as a sibling of the requester instead. The create or update response carries `parentAdjusted` (`max_agent_depth` or `has_children`).
  - New `issues.origin_issue_id` column (migration 0434, exposed as `Issue.originIssueId`). It is set only by the server and feeds `createdFrom` and the `createdFromIssueId` filter.
  - Board users aren't limited, and existing deep trees stay valid.
  - The Runner `create_task` tool gets `parentTaskId`.
- **Every subtask gets its own execution workspace** (`7fd98682c`, #19860). A child never inherits or reuses a parent's or ancestor's workspace, branch or files, by any route. An explicit ancestor `executionWorkspaceId` on create is dropped silently, and only the strategy is kept. `inheritExecutionWorkspaceFromIssueId` now copies only project and strategy. Old bindings are released at the next admission. The New sub-task dialog no longer pre-selects the parent's workspace.
- **Chat navigation restored and extended** (`f5fb8ada3`, #19685; `2e340d623`, #19627):
  - The contact directory comes back, with search and the create-agent dialog.
  - Agent chats can be pinned, with pointer and keyboard reordering.
  - Recents scroll under a fixed heading with no row limit.
  - Unread tasks have bold titles, and the unread dots are gone from Inbox rows.
  - Agent chat pickers show unread counts (new `unreadMessageCount`).
- **Agent profile and setup refinements** (`c650f3600`, #19535; `fd4b197f8`, #19517). The agent header, inline name editing, identity panels and a sticky save footer are reworked, and instruction files now carry `createdAt` and `updatedAt`. Runner dropdowns are removed from agent setup and configuration: selection is automatic, and saved runner settings are kept.
- **Personal AI account defaults** (`377bc87df`, #19845). A crown marks the default account, and "Set as default for OpenAI or Claude" is offered on other eligible personal accounts, with Retry on failure.
- **Native Runner defaults** (`fc6e1b034`, #19888; `02a229917`, #19623). New Codex and OpenCode agents on a local target now run warm (5-minute idle window) by default. Migration 0443 clears the stored `per_turn` value from existing `paperclip_runner` agents unless someone explicitly chose "Turn by turn". The new shared helper `paperclipRunnerCreationLifecycle` holds the rule. Codex now defaults to `gpt-6.1-sol`; `gpt-5.6-sol` is still selectable.

This is an operator and managed-instance feature.
