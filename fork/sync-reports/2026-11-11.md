## Upstream changes

Most of the batch is server-side hardening of the native runtime and Paperclip Runner (about 30
fixes for Retry, resume, suspend, checkpoints, provider state and recovery), an ACPX 0.22.0 upgrade,
and a Better Auth security upgrade with a migration. The change that matters for the fork is #20835.

### Larger new features

- **Workspace storage is the project's only placement choice** (`369e23829`, #20835). Migration 0466
  drops `projects.environment_id` (deleting saved project environments). Runs follow the agent
  default, then the instance default, then local. `Project.environmentId` and the update fields
  `environmentId`, `expectedStorageProviderPluginId` are removed; create keeps them, and
  `POST /projects` with `environmentId` only picks that environment's storage. `PATCH /projects/:id`
  refuses any storage change (`409 project_storage_locked`). The server strips a legacy
  `executionWorkspacePolicy.environmentId`. The old Configuration drops the Environment and Workspace
  storage selectors for a read-only **Available in** list (`GET …/project-environments`), with
  "Storage plugin unavailable" when the project's plugin is gone; the task workspace card drops
  "· project default". No flag.
- **Better Auth 1.7.16 with an account migration** (`81c9143fe`, #18906; `e625505ac`, #20839): a
  security release. Migration 0465 makes `account.issuer` nullable and replaces the issuer index with a
  unique `(provider_id, account_id)` index; it fails on duplicate provider/account pairs and must run
  before the new server. New accounts keep a legacy issuer so an old 1.7.2 process can still sign them
  in during an overlap. No board API change.
- **ACPX 0.22.0** (`ff8ec41e6`, #20770): Paperclip's patched ACPX behaviour moves into Paperclip; the
  `acpx@0.12.0`/`0.13.1` patches become `acpx@0.22.0` in `pnpm-workspace.yaml`. Agent runtime only.
- **Sentry by user auth token** (`34f2bb78e`, #20823): a second, API-key method (`Sentry-Bearer`) in
  the app catalog that doesn't expire. Data only.
- **Runner exports authorized read responses as artifacts** (`84fc67317`, #20606). Agent-side.
- **Plugin task refusals and batched project reads** (`4d141cdf6`, #20762): plugin SDK additions (a
  new export, `scopeKind`/`scopeId` on `PluginEntityQuery`). Rebuild the plugin SDK after the merge.
