## Upstream changes

Almost all of the changes are in the server and the agent runtimes.

- **Tests and CI (about 40):** duplicate tests removed across the server, UI, adapters, end-to-end
  tests and scripts. CI is faster and sends test-run profiles to Honeycomb (`6acec4266`,
  `68a09dcb5`, `676d3ec8d`). No behaviour change.
- **Recovery after restarts (about 15):** queued work is kept when a run is stopped (`6fae6f2cb`),
  older runs a restart stopped before dispatch are retried (`5e8956c20`, `76164b53c`), and remote
  sessions recover while warm runs are kept (`db11d899c`). Deliberate stops and dependency waits
  are preserved (`8d9d2f9dd`). Settled recovery holds and the decisions they kept are now visible
  (`976cdc77e`).
- **Workspaces and git (about 12):** reproducible git files expire and exact commits are restored
  (`59a70dc9e`, `2aca41464`), snapshots are kept separate from controller work (`7fc2dc8b3`), and
  failed workspace restores can be retried (`f1d925b72`).
- **Performance (about 15):** batched permission and skill-dependency reads, readiness no longer
  waits on startup housekeeping (`cda77edc6`), and libc detection no longer looks up a hostname per
  socket (`8ffc5748a`, `cc96c9f83`).
- **Grok agents (6):** fewer routine wakes (`074c67fea`, `7f9d3d192`), new runs wait while the
  connection recovers (`60e03c002`), pairing codes are copied on reconnect (`32ede0891`).
- **Other runtimes:** Claude probe budget (`082423000`), Codex capacity retries (`836587274`),
  OpenCode survives oversized server events (`fd057f6ac`) and keeps managed GitHub access
  (`8843887c2`), Linux ARM64 startup fixed (`854ab294c`).
- **Issue limits:** writes from heartbeat runs with no issue scope count against the cross-issue
  cap instead of being rejected (`7b09e3da7`); finished child issues no longer count toward the
  helper cap (`23e7ee9a2`).
- **Features:** an optional capability for Gmail to archive messages (`e4ce98909`); a generic
  Daytona connection with API and Toolbox access (`0b62c736a`).
- **Tracing:** more detailed spans for workspace setup, connectors and response saving.
- **Dependencies:** mermaid 11 → **12** (major; `ui-new` doesn't use it), smol-toml 1.8 → 1.9, and
  a lockfile refresh (`03f22f4cb`).

Old UI (`ui/src`, excluding tests and stories): 12 files. The main change is a "Recovery details"
panel in the execution blocker notice. Smaller changes to the agent settings form, agent lifecycle
status and Grok Bot connection. Run and activity types gained `wakeupRequestId` and
`queuedCommentSourceWakeIds`.

`packages/shared`, excluding tests: Gmail and Daytona app definitions only.
