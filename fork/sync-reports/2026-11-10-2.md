## Needs your decision

Nothing PROVISIONAL. One change went a little beyond a type fix, so it's listed here to confirm:

- **ui-new project environment read (`8c48f04b5`).** Migration 0464 moves a project's environment
  from `executionWorkspacePolicy.environmentId` into `projects.environment_id` and strips it from the
  policy. ui-new read the policy field, so after the migration a project's "Runs on" (project
  settings) and the routine run dialog's project default would read blank, and clearing an
  environment wouldn't be sent. Now both read `project.environmentId` first and fall back to the
  policy. Clearing still writes `policy.environmentId = null`, which the server still accepts. One
  new test was added. The fuller adoption (grouped choices, New project pick) is U112.

## Upstream changes

Most of the batch makes the native runtime survive restarts: leases, holds, Retry, warm sandboxes
and recovery after a server restart. There are 73 fixes and 20 performance commits, including 5 new
indexes. Few changes are visible on the board: a project's own environment, pull request link
previews, agent plugin tabs by environment, gateway token reveal, and smaller chat and queue fixes.

### Larger new features

- **Each project has its own environment and storage** (`f30ac226d` #20651, `98ce93dd4` #20587):
  `Project.environmentId` (migration 0464) and `GET /companies/:id/project-environments`
  (`ProjectEnvironmentOptions`). Create and PATCH take `environmentId` and
  `expectedStorageProviderPluginId`. The old UI picks it in New project and in Configuration
  (the latter behind `enableEnvironments`).
- **GitHub PR link previews** (`89ec4e761` #20593, `7f72ea753` #20654):
  `GET /companies/:id/link-preview?url=`, board only and cached per viewer. Shown on hover, and
  kept across reloads.
- **Agent plugin tabs depend on the execution environment** (`0d4b1d8c8` #20657): a slot can set
  `agentEnvironmentDriver`, and environments report `pluginDriver`.
- **Gateway token reveal** (`491dfa1c6` #20581, `353945c86` #20613): an agent-created token has
  `pendingReveal` (migration 0463), and the person reveals it with
  `POST /tool-gateway/gateway-tokens/:id/reveal`. Connection intents gain the `reveal_credential`
  kind and the `gateway_token` resource (types only).
- **Tasks open from one batched read** (`2e6850e74` #20592, `d82e5efeb` #20563): `chat-bootstrap`
  for lists, the Inbox and preloading.
- **Warm, reusable remote sandboxes by default** for Codex, OpenCode and Claude on Daytona
  (`1b7ec13ac` #20048).
- **Slack forms and receipts survive retries and restarts** (`12f70d0d4` #19825). It adds
  `POST /chat-endpoints/:id/provider-work/:actionId/retry` and the cloud-only
  `POST /instance/task-drain/status`.

- **Prompts:** agents are no longer pushed to create subtasks (`ce1ee9e89`).
