### Bug fixes

- **Runs and continuation:** a user comment that reassigns a task now resumes its saved follow-up
  (`832c44f26`); a stale `interruptedRunId` hint no longer fails the new assignee's wake
  (`a02be1efc`); a recovered shutdown interrupt counts as recovered on the dashboard's run chart
  (`61ecc9303`); watchdogs reject incomplete subtree scans (`05218571c`).
- **Native runner and computers:** native Stop saves the workspace and saved computers are
  requalified after updates (`f0877a9c7`; the old UI's run ledger reads `run.execution.nextAction`,
  and agent settings qualify the saved computer on test); provider threads always get run-scoped
  readers (`4da876ab0`); plugin sessions keep continuity through warm execution and checkpoint
  recovery (`ea727dc3c`); Claude user-settings trust is kept in `HOME` (`e61ee4b00`).
- **GitHub:** suspended App installations no longer count as repository access, with an access
  retry banner on the App page (`3edba1157`); review replay recovery (`db32bdf98`); resumed review
  waits are kept and Retry picks the newer saved input (`208a093d1`).
- **Adapters:** `pi_local` drops the server's inherited `PAPERCLIP_*` environment (`8153061d7`);
  OpenCode MCP tool results are kept whole (`dcfc2acfa`); ACPX session saves are serialized,
  fixing EPERM on Windows (`2d72f2c4c`).
- **Other:** AWS secret provider errors keep their classification (`585d37d4f`); pipeline capacity
  checks reserve a transaction first (`4336b9ee0`); Artifacts V1 previews fall back to the icon face
  when content 404s (`3e7c3ee9a`).
