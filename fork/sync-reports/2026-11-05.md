## Upstream changes

**323 upstream commits** (`adb49a443..d3713d827`, 2026-11-03 – 2026-11-05)

Most of this batch hardens the native Runner and recovery: 37 `fix(native)`, 26 recovery, 23
workspaces, 18 runner and 7 Daytona commits, nearly all server-side with no board surface. For the
board, it brings a set of old-UI task-chat transcript features, provider usage limits on tasks, one
status glyph for every task view, recovery and Stop changes, Enter-to-send composers, and reads that
survive outages.

### Larger new features

- **Provider usage limit on the task and a hold on the agent's work** (`dd889e6a0` #19270,
  `e37ab23db` #19246). The runner saves Codex and Claude rate-limit windows per agent in
  `agent_runtime_state.state_json.providerRateLimits` (no migration). They show as a "Usage limit"
  line under the assignee in task properties, with a popover. A new live event,
  `agent.runtime_state.updated`, refreshes them, and new runtime exports in `@paperclipai/shared`
  (`provider-rate-limits.ts`) hold the summary rules. While an agent's provider limit is active, its
  queued runs are cancelled as `provider_limit_wait` and retried once at the reset. The task says
  "Waiting for usage limit reset". Manual runs, conversation turns and pool-routed connections aren't
  held.
- **Approving a harness-proposed plan** (`22281d4b3` #19291). Planning runs now put Codex and
  Claude into native plan mode. A completed `plan.proposed` becomes the task's Plan document and a
  `request_confirmation`, on standard tasks too. Approve resumes the agent, and Request changes sends
  the reason back. Receipts read "Approved Plan v1". In transcripts it's a new `plan_proposal` family.
- **Task-chat transcript features**, in the old UI's task chat: the agent's native plan as a card
  above the composer (#19252), tool rows (#19265), Claude subagents as a tree (#19264), an inline
  diff for every file edit (#19269), Codex reasoning summaries (#19271), hook and auto-review
  governance rows (#19266), status notice chips (#19267), an MCP startup failure warning (#19289),
  and rows for web searches, model switches, waits and verification checks (#19262).
- **One status glyph for every task view** (`d80788753` #19329). `blockerAttention` now comes on
  `IssueSummary`, company search results and case issue links. A blocked task covered by an active
  sub-task or dependency shows the blue "in queue" glyph with a reason label.
- **Enter sends task replies and new tasks** (`b400f7664` #19272), and Shift+Enter adds a line. The
  new preference flag `enableLegacyComposerSubmit` brings back Command/Ctrl+Enter.
- **Reads that survive outages** (`2ccc7d37e` #18825, `a3313f694` #18822). An allowlist of reads is
  persisted for 24 hours per user and company and dropped on a build change. `useResilientFetch`
  keeps component reads, query errors are always shown, and run log chunks are kept across stream
  changes. These are the read side of U13.
- **The built-in Google Workspace connector is behind `enableGoogleWorkspaceConnector`**
  (`21640b6d5` #19247). The flag is managed tier, off by default and enforced by the server. While
  it's off, the Composio and Arcade Google apps show.
- **Artifacts V1 for every instance** (`9e9a628a5` #19164). The toggle is removed and a stored false
  is ignored. Only managed config can hold it off.
- **Plugins:** managed config can grant worker environment variables and enable plugins per
  company (#19049). This is operator-only.
- **Project concurrency storage** (`fef86e32e` #18746, `ce332ecec` #18871). New tables hold
  execution admissions and per-project `max_concurrent_tasks`. No API exposes them yet. Deleting a
  project or agent returns 409 while an admission is unsettled.
- **Runtime, with no board surface:** per-turn Runner sessions on ephemeral web servers with harness
  state backups (#18932), a private host control channel (#19129), sleep-blocker diagnostics
  (#18632), and domain deadlines across idle sleep (#18656).
