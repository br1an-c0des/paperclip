## Upstream changes

Most of this batch is work toward Google Workspace's restricted-scope review: a way to delete the
data a connection read, a data-use disclosure in the Google picker, the scope list cut to the 14
submitted scopes, and Gmail and Calendar tools on Google's REST API that nothing calls yet. The rest
is Paperclip Runner and native-runtime fixes found in restart-chaos runs, three old-UI fixes (inbox
badge, Routines, connector permissions) and Cloud-only analytics.

### Larger new features

- **Delete data read through a connection** (`d1b5cfe03`, #22010): any tool connection can delete
  what it stored: tool-call results, approval previews, app views and the run transcripts that hold
  tool output. On the connection's page, and as an option when removing it. API:
  `GET /tool-connections/:id/stored-content`, `POST|GET /tool-connections/:id/stored-content/deletion`,
  `DELETE /tool-connections/:id?deleteStoredContent=true`; shared types `ToolConnectionStoredContent`,
  `ToolConnectionContentDeletion`, and `contentDeletedAt` on the connection. Migration
  `0490_nappy_chat` (`tool_connection_content_deletions`), with a background worker. No flag.
- **Google Workspace data-use disclosure** (`b124ad067`, #21998): the old UI's Google service picker
  shows what data is accessed and how it is used before Google's consent screen, changing with the
  chosen services and access levels. Reconnect on a Google Workspace connection now opens the picker
  too.
- **Gmail and Calendar tools on Google's REST API** (`a29658b5b` #22000, `c41ca4a99` #22017): a new
  `server/src/google-workspace-rest-tools/` folder that keeps Google's MCP tool names and inputs.
  Nothing outside the folder imports it yet, so no behaviour changes.
- **Runner: a relaunched Runner can resume** (`bc0a236b9`, #21976): a released Runner that is
  relaunched is accepted if its build can resume the session. Adds a field to the plugin SDK's
  environment-tasks contract. Server and Runner only.
- **Cloud only:** server analytics go straight to PostHog (`55b692d53`, #22006; adds
  `posthog-node`), and a signed run-liveness check for the inspection authority (`7b1c01a8a`,
  #22005). Self-hosted installs don't change.

### Bug fixes

- **UI (old UI):** the inbox badge counted for every user, and now counts only the signed-in user's
  items (`a5da0f603`, #21953). Routines loaded folders late, which made the list jump and showed
  "Unknown folder"; its toolbar is trimmed (`35c452688`, #22009). Connector permission forms were
  slow on large action lists (`a312bdd34`, #22008).
- **Connections and Google:** the Google client could request scopes outside the 14 submitted to
  Google (`66ac5d7aa`, #22001). MCP resource reads now go through the prompt-injection screen, with
  tests that Google results are screened (`65eac2487`, #21999).
- **Agents, runners and the native runtime:** a Runner caught while exiting was reported as running,
  failing an idle warm close (`ca34aca77`). A failed warm session's cleanup could stall the task,
  and now finishes by itself (`22d3f9a03`). A run reporting a temporary system-environment blocker
  stopped, and now continues (`7685b7a4f`). Later reports after an accepted result were refused
  without saying it was final (`41b0f76d7`). "As the file reads" was taken for a file request
  (`ddb2b2505`).
- **Tasks:** a finished blocker whose run had already ended never released its parent (`b2b2c1e60`,
  #21948).
- **Workspaces:** plugin-owned workspaces logged a "replace" drift notice on every run after a
  sandbox template change; it now appears once (`79c8cf8b6`, #21947).
- **Auth (Cloud):** an unchanged tenant sync could hold up a signed-in user's requests (`3659a3a94`,
  #21997).
- **Diagnostics:** blocking database sessions are logged for stalled event writes and reattach
  (`3afb2c215`, `d8a5db36e`).
- **Adapters:** Claude Opus 4.5 in the Claude adapter's fallback model list (`5e53fec10`, #12379).
