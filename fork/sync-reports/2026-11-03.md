### Migration 0423 and Bob

`0423_agent_config_read_defaults.sql` runs once. It inserts a company-wide (`scope` NULL)
`agents:read` grant into `principal_permission_grants`, and writes an `agent.permissions_updated`
activity row (`actor_id` `migration:agent-config-read-defaults`), for every agent that meets all of
these conditions:

- an `active` agent membership in its own company;
- `status` not `pending_approval` or `terminated`;
- `lifecycle_state` in `ready`, `pausing`, `paused` or `resuming`;
- no `setup` lifecycle hold and `pause_reason` not `setup`;
- not a managed built-in (`metadata.paperclipBuiltInAgent` absent);
- trust preset `standard` in both `permissions.trustPreset` and
  `permissions.authorizationPolicy.trustPreset` (a missing value counts as standard);
- no `low_trust_review` review preset in either place, and no `authorizationPolicy.trustBoundary`;
- no existing `agents:configure` or `agents:suggest-changes` grant with a non-empty scope.

An existing `agents:read` grant is left alone (`ON CONFLICT DO NOTHING`), and existing write grants
are unchanged.

**Bob (`8997b521-5718-4fce-988f-e79a301dc876`):** going by the migration alone, Bob gets the grant
when the server next starts on this code, provided he is:

- an ordinary hired agent (not a built-in), ready or paused;
- on the standard trust preset, without low-trust review or a trust boundary;
- without a scoped configure or suggest grant.

The fork docs describe Bob as an ordinary Claude Code agent that you chat with. Nothing in them
mentions a non-standard trust preset or a built-in, so he is probably eligible. I didn't query the
live database, as asked, so that is not confirmed. Bob is not eligible if any of these is true:

- he was set to low trust or given a review preset;
- he is still in setup;
- he holds an `agents:configure` or `agents:suggest-changes` grant limited to particular agents.

If he is eligible, his activity will show one "permissions updated" entry from the migration. He can
then read other agents' configuration and instructions (redacted), with no new write access.
