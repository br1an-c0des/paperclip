## Upstream changes

Mostly server and Runner work, led by git workspace restore points. For the redesign, the parts that
matter are the new artifact presentation, the reworked agent roster, dismissible requests and the
routine link on tasks.

### Larger new features

- **Artifacts V1** (`341b622604`, #17228; design lab `def4726bea`, #17213): a new presentation for
  artifacts on the Artifacts page (paper stacks and tiles), the panel's Artifacts tab (compact rows)
  and the task thread (grouped rows). It sits behind a new experimental flag, `enableArtifactsV1`
  (off by default). The lab in `ui/src/artifact-directions` is a backend-free reference with the
  shipped baseline, four directions and the MVP V1 kit.
- **Agent roster bulk edit** (`9bf7dc0c8f`, #17215): change the AI connection and default model for
  many agents at once, filtered by harness, with previews, per-agent results and retries. The roster's
  status tabs are gone, and old tab URLs redirect to the full roster.
- **Routine link on tasks** (`93d26eb84e`, #16471): a routine-created task shows a "Routine" row
  under Relationships that links to its routine (UI only, from `originKind = "routine_execution"`).
- **Dismissing requests** (`46760cc588`, #17218): any request in a task conversation can be
  dismissed to history (`POST /api/issues/:id/interactions/:interactionId/dismiss`, migration 0373).
  Dismissed requests stop gating completion and composer reminders.
- **Project access repair** (`d0c8f0b090`, #17509): a project access denial is explained on the task,
  and agent settings can add projects to the agent's scope (`GET|POST /api/agents/:id/project-access`).
- **Runner qualification** (`0eb2c964a7`, #17448): `POST /api/agents/:id/qualify-runner`, allowed
  with the agent configuration permission.
- **Git workspace restore points** (about 15 commits, including #17238, #17241, #17248, #17257,
  #17271, #17269, #17290, #17472): closed and idle worktrees expire after their unsaved work is saved
  as an encrypted restore point, kept 90 days. Reopening a task after that starts a fresh workspace
  with a warning. Nested repository checkouts share one project clone (#17382, #17369, #17407, #17410).
  Server only; no new UI.
- **Connections:** 1Password service-account connector (#17249), Supabase and Vercel deploy and
  configure (#17217), Unikraft Cloud (#17139).
- **Onboarding:** connect a custom AI gateway while setting up the first agent (#17253).
- **Slack:** complete questions and review decisions inside Slack conversations (#17255).
