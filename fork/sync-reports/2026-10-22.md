## Upstream changes

About 75 fixes, 11 performance changes and 15 features, plus refactors, docs and tests.

- **Pipelines removed (`907774889`):** the Pipelines experiment is gone from the UI, API and CLI:
  boards, stage settings, case automation, review queue and learnings. Its database tables and
  migration history are kept. The `enablePipelines` flag and 16 routes are gone.
- **Cases rebuilt around handoffs (`505e1a558`, `0a5f1546e`, still behind `enableCases`):** a case can
  have one primary task that agents hand off to each other through phases, with durable handoff
  records, native case tools for agents, and reusable company workflows (a name and a Markdown
  prompt). The board's case pages are now read-only: list (with a type filter) and detail (details,
  parent and child cases, documents, attachments, handoff history). Adds migrations 0363–0368 and 0371
  (`case_handoffs`, `case_access_sources`, `workflows`, new columns on `cases` and `case_events`).
- **Task Retry and saved-work recovery (`d33b40a5c`):** an interrupted task now shows one state ("Retry
  available", "Trying again in Ns", "Taking longer than usual") with a single Retry
  (`POST /api/issues/:issueId/retry`), offered on the task, in task lists and in the Inbox. The
  "Recovery details" panel and the "Continue from saved sources" form added in the last two syncs are no
  longer used by the old UI. Adds migrations 0360 and 0369.
- **New company settings:** agent observability, which sends OpenTelemetry logs and traces from managed
  Codex and Claude Code runs to a company destination (`ac9459bae`, migration 0357). Prompt injection
  prevention, an optional model check on tool results with a regex fallback, is on Connections
  (`2c96f7678`, migration 0362). Decision model setup is now always on Connections.
- **Agent commentary in Audit (`e6dcd1e8e`):** a Commentary tab (`/activity/commentary`) for the
  suggestions and complaints agents submit, with filters and shareable links. Migration 0359 grants
  humans read access by default.
- **Paperclip Runner by default:** new Claude agents on Apple Silicon and on qualified macOS and Linux
  targets (`45b67f1d9`, `8193abb93`), and new OpenCode (`39e44a9d9`) and Pi (`734c26533`) agents.
  Existing Claude and Codex agents get an "Upgrade to Paperclip Runner" offer (`0f15f82b1`).
- **Connections:** GitHub Copilot connected and configured through Apps and packaged for ordinary
  installs (`92b238137`, `d855e550a`, `df80616d9`, `7c247243e`); a unified Google Workspace connector
  (`23b2ceb0d`); Braintrust (`92cfd701c`) and Ditto (`a1e2173ce`) connections; an experimental
  Paperclip Notebook MCP connection behind the new flag `enablePaperclipNotebook`, which the UI doesn't
  read (`3ce8d976a`).
- **Plugins:** agent detail tabs and authenticated WebSocket routes (`42715d459`); plugin-owned project
  storage and task workspaces (`8b4ab65b1`); lease-scoped Runner task hooks (`33cc567f7`); instance
  secrets for project lifecycle plugins (`65f59e339`); plugin runtimes are invalidated when tool
  definitions or connector access change (`194fc1140`, `313fb265d`, migrations 0355 and 0356).
- **Behaviour changes:** onboarding saves a paused agent record as soon as the name is submitted
  (`79b2bf78d`). Inbox Mine leaves out channel and routine work unless the person takes part, is
  assigned or has a request addressed to them (`a2d26a83f`). Task assignment changes carry a status
  version (`7c58ea07b`, migration 0358).
- **Performance (11), plus 6 "stop idle polling" fixes:** faster task loading and recent tasks in the UI
  (`fa50cab56`, `d5b92cc41`, `3e5a9f5af`, `4d9258979`), asynchronous budget enforcement (`30b753f61`),
  sandbox startup reuse (`98ca6ff7c`), and less polling when idle (login cleanup, execution-control
  recovery, MCP events, skill sources, Muse maintenance).
- **Other fixes:** mostly Runner (completion recovery, tool argument and result errors, OpenCode and
  ACPX), workspace recovery and locks, GitHub review comments and reconnection, heartbeat retries,
  skills attachment, and chat scoping.
- **Refactors:** 10 commits isolate ownership inside the tools subsystem (`9db3a5726` to
  `4dfcb4c9b`). Docs: module ownership, feature map IDs, a native Runner integration playbook.
- **Dependencies:** no version changes to existing packages. New: `@opentelemetry/otlp-transformer`
  0.221.0, `@opentelemetry/resources` 2.10.0, `protobufjs` 7.6.6 (observability) and `smol-toml`
  ^1.9.1. Server and Runner gain a `postinstall` that prepares Copilot assets.

Old UI (`ui/src`, excluding tests and stories): 231 files, +9,499/−16,074, mostly from Pipelines
(`Pipelines.tsx`, `PipelineSettings.tsx`, `api/pipelines.ts`) and the smaller Cases pages. Agent
detail routes now go through `pages/AgentDetailPage.tsx`, which renders `AgentDetail` or a plugin tab.

`packages/shared`, excluding tests: pipeline types, validators and health removed;
`project-mentions.ts` removed; case handoff and workflow types; agent commentary, observability and
prompt injection prevention contracts; Google Workspace connector services; issue summaries and
interruption state on tasks.

Migrations (17): 0355–0371, listed by feature above. 0361 changes the AI connection and provider
default tables, and 0370 changes `company_secrets`.
