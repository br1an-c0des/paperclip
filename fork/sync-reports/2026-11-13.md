## Upstream changes

About three quarters of the batch is more native runtime and Runner hardening: recovery, Retry,
continuations, heartbeat and dispatch (about 170 fixes), plus about 45 evals and chaos-test commits.
Four larger pieces of board work matter for the fork. The biggest is personal request routing in the
Inbox (#20959, #20961), a new model of who a request belongs to. The other three are a redesign of the
Secrets page, MCP Apps views in the task chat, and MCP Skills review.

### Larger new features

- **Personal request routing** (`8818402e7`, #20959; old-UI rebuild `cf1def0ca`, #20961). No flag.
  - **Views:** attention cards carry an `audience` (a user, a pool or the company). `GET /attention`
    takes `?view=mine|unassigned|company|archived|all` (default `all`) and returns `viewCounts`.
  - **Actions:** new `POST …/attention/:sourceKind/:sourceId/claim`, `/transfer` and `/close`
    (withdraw, archive or snooze).
  - **Hiding:** dismissals take a `fingerprint`, so a hidden card returns when it changes.
  - **History:** receipts for requests someone else handled. History gains `scope`/`handledForMe`
    and action outcomes, and `issueId`/`issueTitle` can be null.
  - **Approvals:** `POST /approvals/:id/cancel` withdraws an out-of-date approval.
  - **Owners:** companies gain `defaultDecisionOwnerUserId` and `budgetOwnerUserId`, and projects
    gain `decisionOwnerUserId` (migration 0469).
  - **Badge:** `deskBadgeCount` now means "For you".
  - **Server-side:** closed-task requests and replaced confirmations drop out of current cards.
  - **Old UI:** opens on Assigned to you, with compact cards, a Close… menu, claim/transfer, a shared
    review side panel and an "Other" radio on questions.
- **Settings → Secrets redesign** (`826d41e64`, #21225).
  - The list shows the team's secrets, with Provided by and Used by columns. Credentials Paperclip
    saved fold into "Managed by Paperclip".
  - One Filter menu replaces the old controls. New secret becomes a single step. The details panel is
    one scrolling view, and Vaults is one flat list.
  - API: optional `order`/`limit` on the secret-proposals list.
- **MCP Apps views in the task chat** (`8ff45c0fa`, #21119; `8af889f61`, #21266). Connected apps
  (Circleback first) render a sandboxed iframe under their tool calls.
  - New `GET/POST /issues/:id/mcp-app-views[/:viewId[/tool-calls|/messages|/model-context]]` and
    `GET /companies/:id/tool-icons`.
  - Messages the view proposes need consent. Full screen and app context. Migrations 0473 and 0477.
    No flag.
- **MCP Skills review** (`2d1c2db64`, #21219). Connected apps publish skills that wait for board
  review: `GET /companies/:id/mcp-skills`, `…/content`, `/approve`, `/decline`. Migration 0474.
- **"Move it forward now"** (`d9b42b50f`, #21373; `5026093d0`, #21385). The interruption carries
  `retryAction: "move_forward"`. `POST /issues/:id/retry` takes it and can answer `alreadyMovedOn`.
- **MCP Tasks** (`944b1c64d`, #21263). Long provider tool calls become durable tasks (migration 0478).
  Behind the new instance flag `enableMcpTasks`, off by default.
- **Configuration warnings on save** (`2483cb46c`, #21280). `Project` and `Routine` responses can
  carry `configurationWarnings`. The same commit delivers configured environment variables to plugin
  Runner tasks.
- **Agent pages and org chart refresh** (`9dfdeaad8`, #20973). Instruction files can be renamed
  (`renameTo`), and avatars gain `?view=portrait`.
- **AI Connection sign-in picks the computer automatically** (`25f0957c2`, #20906).
- **Browser page-load tracing to Honeycomb** for hosted instances (`eaef46b60`, #21156;
  `51c81c537`). Adds OpenTelemetry devDependencies to `ui/`, and moves the old UI's route tree into a
  local const, which broke the inventory script (fixed below).
- **Runner and CI infrastructure:** managed plugin Runner lifecycle, managed workspaces on the active
  Launcher, asynchronous workspace provider preparation, Runner image variants, and stateless MCP
  2026-07-28. All agent-side or ops.
