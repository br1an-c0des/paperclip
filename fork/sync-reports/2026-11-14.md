## Upstream changes

About two thirds of the batch is server work again: 87 fixes and 44 perf commits on the native
runtime, Runner, recovery, dispatch, run events and the database pool, plus a series on
"provider-started turns" for Claude and ACPX. The board-facing part has three themes:

- Honest queue states: a task waiting for an agent's slot no longer looks live.
- Connected apps doing more inside the task chat: live progress on long calls, and form questions.
- New connection plumbing: Tailscale networks for SSH environments, machine sign-in for
  organization connections, and a redesigned sign-in step for pasted MCP servers.

Nothing changes the Inbox or request routing model from #20959. The Inbox commits are server perf,
plus an old-UI trick that shows "Mine" from the saved cache.

### Larger new features

- **Waiting for an agent's slot, with place in line** (`e7e28ba24`, #21405; `833689a3f`, #21447;
  `6dd0349d5`, #21564). No flag.
  - A queued run that never started is no longer shown as live or working.
  - `ExecutionProjection.agentQueue` (`agentName`, `maxConcurrentRuns`, `runningCount`, `position`,
    `queuedCount`) and cause `agent_at_capacity` give "Waiting for Codie · 20 slots max · 41 of 295
    in line · Configure".
  - A routine hold is cause `routine_execution_in_progress`, "Waiting for <task> to finish".
  - After 30 s with no named hold, the old UI shows "Waiting to start".
  - `Issue`/`CompactIssue.runningDescendantCount` counts only started descendants, and the sidebar's
    live counts leave queued runs out.
  - Stop on a run still waiting in line returns the task to `todo` (`e40a16e5c`, #21407).
- **Live progress for long connected-app tool calls** (`a726dce4f`, #21449).
  - `GET /issues/:id/tool-call-progress` and the live event `heartbeat.run.tool_progress`.
  - Shared `ToolCallProgress` types. Migration 0484.
- **MCP elicitation** (`a4c570aed`, #21466).
  - An app's form question becomes a human-only `ask_user_questions` card, "<App> needs your input",
    with a `questionSet` and "Send to <App>".
  - Skip on an app's question wakes the agent.
  - Password, key and token fields are refused.
  - Migration 0483. It uses the existing interaction routes.
- **Tailscale networks for SSH environments** (`21bf7ebce`, #20617; `0a96f972e`, #21526).
  - The old-UI route `/apps/tailscale` and a Tailscale card in Apps.
  - `…/tailscale-connections` endpoints: list, connect, device-login, devices, disconnect, pairing,
    and an OAuth callback.
  - A Network choice (Direct or Tailscale) with a machine picker and pairing in the SSH environment
    form.
  - System-owned secrets (`company_secrets.system_purpose`), which are hidden from secret lists.
  - Migrations 0480–0482. Upstream's Docker image now ships `tailscale`.
- **SSH environments use the agent's AI account** (`12aa08721`, #21248).
  - `SshEnvironmentConfig.useHostAuth`. The old UI saves `false` for new environments and has an
    Advanced toggle.
  - A missing field means host auth.
  - Agent create or test without host auth needs an AI account (`422 ssh_ai_connection_required`).
- **Machine sign-in for organization connections** (`f6c5986b6`, #21473; `84cb28f9b`, #21566).
  - OAuth client credentials, with a key Paperclip holds or a client secret.
  - Five endpoints under `tools/machine-sign-in` and `tool-connections/:id/machine-sign-in`.
- **Redesigned sign-in step for a pasted MCP server** (`0199c963e`, #21469).
  - A stated default with Change, and five options with their fields below each.
- **New tasks save in the background** (`bb253c6a9`, #20831).
  - The dialog closes at once.
  - A failed save reopens its draft, or is offered as a retry beside another open draft.
- **Refused Retry** (`3b03ac10e`, #21497).
  - `POST /issues/:id/retry` waits up to 5 s for admission.
  - A refusal answers `accepted: false, refused: { reason, message }`.
- **Server-only:**
  - provider-started turns (#21422, #21420, #21421, #21423, #21316, #21453, #21454, #21455, #21607)
  - the automatic-run brake (#21443, #21561, migration 0485)
  - the run's environment for plugin workspace providers (#21512, #21352)
  - Slack progress without extra messages (#20827)
  - an MCP Tasks demo server (#21464)
  - CI merge-queue checks
